# Art for Clash Classic

Drop files in this folder with these names and the site picks them up. No code changes needed.

| File | Where it shows | Suggested size |
|---|---|---|
| `logo.svg` | Top-left of every page | Square or wide, at least 80px tall. SVG or PNG (if PNG, rename it in `index.html`) |
| `favicon.svg` | Browser tab icon | Square, simple shapes |
| `hero.jpg` | Banner on the home page, behind the title | About 1920 x 700. Keep the left side darker, the title sits there |

Colours, fonts and other images are set in `theme.css` at the top of the site folder. Each line there has a comment saying what it changes.
